# Supabase 云端同步 · 配置清单

本目录把「哪些数据上云、怎么上」整理成可落地的配置。代码侧已全部改好，**你只需在 Supabase 控制台按下面几步操作即可启用**。不做这些操作时，网站会自动走原来的本地存储 / 自建后端，页面照常用，不会坏。

---

## 一步总览

1. 建表（跑 SQL）
2. 开启邮箱登录
3. （可选）关闭邮箱验证，方便自测
4. 注册一个账号，登出/登入体验多端同步
5. （可选）给自己开 VIP

---

## 第 1 步：建表

1. 打开 https://supabase.com/dashboard → 进入你的项目（URL 是 `otrmipumtinzhxmxbvvb` 那个）。
2. 左侧点 **SQL Editor** → **New query**。
3. 把本目录 `schema.sql` 的全部内容粘贴进去 → 点 **Run**。
4. 看到 `Success. No rows returned` 即成功。脚本可重复跑，不会破坏数据。

建好的表（RLS 已开启，按账号隔离）：

| 表 | 用途 | 梯队 |
|---|---|---|
| `bills` | 月度收支 | 一 |
| `navigator_sites` | 宝藏导航（**只有网址/名称/分类，无密码字段**） | 一 |
| `notes` | 随心笔记 | 二 |
| `products` | 商品目录 | 二 |
| `score_rules` | 分数换算规则 | 二 |
| `rank_tables` | 一分一段表 | 二 |
| `profiles` | 用户资料 / VIP 权限 | 三 |

---

## 第 2 步：开启邮箱登录

1. 左侧 **Authentication** → **Sign In / Providers**。
2. 找到 **Email**，确认是 **Enabled**。
3. 按需取消 **Confirm email**（关掉后注册即登录，自测更方便；正式对外的网站建议开启）。

> Supabase 免费版发的确认邮件有频率限制。若你只是自己用，关掉 Confirm email 最省事。

---

## 第 3 步：开始使用

1. 打开你的网站，右上角导航栏会出现一个 **「仅本机 / ☁️云同步」** 的小胶囊按钮。
2. 点它 → 注册一个云账号（邮箱 + 密码）。
3. 登录成功后胶囊变成绿色 **「云同步」**，此时：
   - **笔记**：自动上传云端，换电脑登录同一账号即可看到。
   - **宝藏导航**：站点清单从云端读取。
   - **账单**：记录存到云端，按账号隔离。
   - **分数规则 / 一分一段表**：配置跟随账号。
4. 未登录云同步时，以上功能全部回退到原来的 localStorage / 自建后端，行为与改造前一致。

登录页（`/login`）底部也加了「云同步账号」注册/登录入口，两条路等价。

---

## 第 4 步（可选）：开通 VIP 权限

云账号的 VIP 由管理员控制，用户自己改不了（安全设计）。在 **SQL Editor** 执行：

```sql
-- 给指定邮箱开通一年 VIP
update public.profiles
set vip = true, vip_expires_at = now() + interval '1 year'
where email = '你的邮箱@example.com';

-- 设为管理员（可选）
update public.profiles set role = 'admin' where email = '你的邮箱@example.com';
```

执行后让该用户**退出并重新登录**云账号，VIP 状态即可生效（可访问宝藏导航等会员模块）。

## 安全说明（重要）

- **导航密码箱**：按你的要求，链接不可点击；账号密码**不写进代码、不存云端、不写 localStorage**，只在点击「临时填写」后存在于当前页面内存，关闭或刷新即消失。云端 `navigator_sites` 表里根本没有密码字段。
- **数据隔离**：所有业务表都开了 RLS，行级策略是 `auth.uid() = owner_id`。即使前端的 publishable key 是公开的，别人也读不到你的数据。
- **publishable key**：写在 `src/utils/supabase.js` 里。这是**公开key，可以放在前端**，安全性由 RLS 保证。千万不要把 `service_role` key 写进前端代码。
- **VIP 防篡改**：`profiles` 表只开放「读自己的行」，没有给用户开放 update 权限，所以无法通过接口把自己改成 VIP。

---

## 数据迁移说明

- 改造**不迁移历史数据**。你之前存在 localStorage 的笔记、分数规则仍在那台电脑的浏览器里，登录后新产生的数据会写云端。
- 如需把某台电脑的旧笔记批量搬到云端：登录云账号后，在那台电脑打开笔记页 → 确认能读到旧笔记 → 随便做一次编辑触发保存，即可把整包笔记 upsert 到云端，再在其他设备登录即可看到。
- 导航站点清单：内置清单作为未登录时的兜底；登录后以云端 `navigator_sites` 表为准（当前表为空时会继续显示内置清单）。如需自定义站点，在 Supabase 表里插入行即可。
